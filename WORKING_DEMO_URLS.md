## 📞 Troubleshooting

### "Trade not found" Error?
- ✅ **FIXED**: Now using actual database UUIDs instead of `trade_001` format
- Verify database was seeded: `npx prisma migrate reset --force`
- Check trade exists: `npx tsx scripts/get-demo-ids.ts`

### "Dispute not found" Error?
- ✅ **FIXED**: Now using resolver case IDs instead of dispute IDs
- The dispute page expects resolver case IDs (from `resolverCase` table)
- All 5 disputes have resolver cases assigned

### Wrong Port?
- Use port **3000** only
- NOT 3001 or 3002 (old instances)
- Kill old servers: `lsof -ti:3001 | xargs kill -9`

### Slow Loading?
- First load is always slower (3-5s)
- Subsequent loads should be 0.24s
- If still slow, restart server
